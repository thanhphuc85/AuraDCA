Aura DCA

An autonomous DCA agent that lets Claude drive strategy — while code owns every number that touches money. Built on Arc Network.

01 · The problem

You can't let an LLM
be the final authority on money.

Give it the keys and one hallucinated number drains the wallet. Take away all its agency and it's just a cron script with extra steps.

And the moment the money isn't yours, it must be fair as well as safe — every user's schedule honoured, every user's funds ring-fenced, every allocation reconstructable — while still settling efficiently on-chain.
02 · The solution

Claude recommends. Code decides.

🧠 Claude — the agent

Recommends an amount + reasoning.

Reads balance, day count, budget, its own history.

{ proceed, amountUsdc, reasoning }

Never trusted with the final number.

🔒 clampDecision() — the code

Decides the amount actually swapped.

Re-derives the cap from hard guardrails: max/day, reserve, dust, campaign budget.

Sole authority. Pure function. Unit-tested.

Records boundBy — which rule bound the result.

03 · The flagship claim

Many users. One swap. Fair settlement.

  • 1Each wallet sets its own cadence, amount, and caps.
  • 2Every run, the agent executes the sum as a single swap per token.
  • 3Proceeds distributed pro-rata by contribution — remainder assigned deterministically so the books always close.

One transaction serves everyone. Nobody subsidises anyone.

05 · Non-custodial by construction

Both halves of Circle's wallet stack.

🤖 The agent

Developer-Controlled Wallet — Circle custodies the signing key server-side. No raw private key to leak in a CI secret.

👤 The user

Sign in with Google → a real, non-custodial User-Controlled Wallet on Arc. MPC custody, PIN recovery — no MetaMask, no seed phrase.

Every state change is authorised by the user's own signature. The agent executes the strategy — it can never invent a user's consent.

06 · It audits itself

The ledger is tamper-evident on-chain.

After each run the agent records keccak256(data/ledger.json) in AuraAttestation.sol — a purpose-built Arc Testnet contract only its wallet may write to.

07 · The honest state — and why it's a strength

The agent knew when not to act.

USDC → cirBTC returned "No route available" across 14 distinct days — a liquidity outage on Arc Testnet, not a bug in the agent (proven isolated by check-routes).

It recognised the failure as structural, not transient, wrote that to its own reflections, cut its probe frequency, and withheld spend to preserve capital — unsupervised. Pick EURC and buys settle live today; leave it on cirBTC and the agent rides out the outage. Both run side by side.
08 · Programmable money, one layer deeper

The agent pays for its own inputs.

Beyond spending USDC to accumulate, it can pay per call over x402 (HTTP 402): a metered "market brief" unlocked by a signed USDC authorization — EIP-3009 transferWithAuthorization.

npm run x402-demo  # one command · no keys · no setup

Honest scope: signed & cryptographically verified, settlement gated off — an additive module (12 tests) that never touches the DCA pipeline.

10 · What makes it stand out

Proven, not asserted.
